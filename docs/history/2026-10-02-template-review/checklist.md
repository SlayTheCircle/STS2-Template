# 模板独立开发专项审查

本页归档当次专项审查使用的两种起步条件与接受标准。源码检查、编译和诊断素材打包提供相应层次的证据；全套实现还需真实游戏、存档、界面与设计者裁定。日常验收方法见[验证纪律](../../dev/testing.md)。

## 两种输入边界

| 角度 | 可用输入 | 不可依赖 |
|---|---|---|
| 本机开发 | 模板、该 Mod 的 local_dev 设计与美术、自己安装的游戏、共享原版源码、RitsuLib 和工具 | 其他角色 Mod 的私有文件、已生成素材、未整理事故知识、隐藏路径 |
| 外部贡献者 | 干净模板克隆、自己的设计与有权使用的美术、自己的游戏与对应 RitsuLib、公开 API 文档 | 组织私有 circle-refs、美术仓、维护者 local_dev、组织密钥 |

游戏、SDK、RitsuLib、Godot、ImageMagick 是显式环境依赖，不由模板分发。本机地图填写实际位置；外部贡献者按 CONTRIBUTING 配置。共享原版资料允许复用，但不得混用不同游戏版本。

## 审查步骤与通过条件

| 阶段 | 实际操作 | 必须观察到的结果 |
|---|---|---|
| 派生 | 先源码检查，再初始化；包括多词短名、缩写、特殊字符显示名 | 检查不污染工作树；键符合 RitsuLib；来源保留；私有入口生成；模板验收不继承 |
| 设计整理 | 提取花名册、升级表、机制状态作用域、事件、先古与世界线清单 | 每项有消费方或明确延后项；歧义先裁定；示例从类、初始卡组、池、文本和映射同步替换 |
| 内容骨架 | 按 Base 家族、注册特性实现并拆分目录 | 注册、复合键、占位符、花名册审计覆盖移动后的内容；显示名不替代类型身份 |
| 机制 | 按同版本原版先例实现预览、结算、升级、临时与持久状态 | 变量三件套、卡源、关键词、跨牌堆状态、战斗结束和取消边界符合设计 |
| 美术 | 配映射并运行 prep-art；补角色、能量、事件、纪元资源槽 | 缺母版时在写入前失败；重复生成不改字节；必需资源入 PCK、可加载且尺寸正确 |
| 可选模块 | 按公开事件与世界线指南接线 | 能自然进入目标事件或界面；奖励、三池过滤、缩略图、大图、对话轮次分别生效 |
| 双版本 | 每目标用配对引用编译；同一 Loader 跑两版验证进程 | 零错误；告警有解释；模型发现；旧依赖在内容初始化前拒绝 |
| 发行物 | 本地 package.sh；选择匹配目标的候选包 | 二进制与候选来源相符；许可、安装说明、校验值齐全；不要求组织凭据 |
| 游戏验收 | 授权后部署；新档和已有档开局、战斗、奖励、存读档、可选模块 | 注册日志无未处理错误；效果与文本一致；被测 DLL 确实包含本次修改 |

## 常见事故防再生核对

逐项使用 [事故与防护](../incidents.md) 核对实现、自动检查和游戏证据。存在文档规则不计为运行验证。关注运行中覆写 PCK、SIGPIPE、变量改名、预览三件套、资源多槽、关键词快照与全牌堆、场外 Power、初始化器补丁、初始遗物获取时替换、时间线基类与缩略图、夹击缩放符号、旧部署物和稀有度术语。

## 结果记录

当次记录输入快照、游戏与依赖版本、命令、证据、未通过项和未执行项。实际路径只留在 local_dev；公开执行结果归档于[验证记录](validation.md)。诊断素材完整包通过不能记为正式美术验收；Loader 隔离验证不能记为真实初始化或菜单验收。

本清单是审查方法的历史记录，本身不声明全流程已经通过。
