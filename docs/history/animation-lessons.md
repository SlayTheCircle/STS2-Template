# 原生角色动画工程案例（2026-10）

这些案例来自游戏 0.107.1／0.111.0、Godot 4.5.1 原生角色动画的开发实践。通用操作见[动画入门](../dev/animation/README.md)，具体角色自行选择美术风格与动作。

| 现象 | 原因与取舍 | 可复用检查 |
|---|---|---|
| 结算和地图上仍出现完整角色 | 内部较大正 z_index 越过父战斗场景层级；改用局部绘制顺序 | 角色可见、前景覆盖、祖先淡出三组真实像素检查 |
| 大幅弯曲中段出现扭曲 | 整段网格反转或剪切；改用独立段、转轴与针对性关节结构 | 采样中间姿势，结合拓扑检查、纹理比例和目视审查 |
| 修正反转后仍不自然 | 数学约束满足，但纹理伸缩、关节重叠和重心节奏仍有问题 | 正常速度、慢放、局部放大和最终显示尺寸分别审查 |
| 相邻肢段像两块素材叠在一起 | 接缝缺少连续表面，端帽重叠 | 按运动范围设计裁切、覆盖和关节补画，检查最大转角 |
| 支撑部位全程僵直 | 为避免穿地而固定整段，限制了重心变化 | 按动作设计接触点与阶段，地面约束和自由移动分开处理 |
| 另一个角色同步变形 | 多实例共用了可变材质状态 | 同时实例化两份，改变一份并核对另一份的姿势与参数 |
| 恢复或回待机时跳变 | 网格、附件显隐、排序或骨段未完整复位 | 声明需要连续的端点，另测重新进入和状态打断 |
| 预览通过而包内仍是旧素材 | 预览来源、生成目录与安装包脱节 | 记录来源哈希，检查实际 PCK，再对照安装／工坊下载字节 |

一次下蹲动作曾通过腿段拆分、关节布面与分阶段支撑改善；该方案适用于它的素材与动作幅度。可迁移的是“定位变形来源—选择表示方式—补足关节—验证运动中段”的方法。漂浮、消散、整身倒地等动作有各自适合的结构。

制作工具也应按团队条件选择。先用小规模动作验证脚本组装、编辑器或混合制作是否可控，再投入完整角色。生图主要解决外观与补画，动作时序、关节连接和游戏生命周期仍由工程接线与审查完善。
