# 素材与动作设计

## 分阶段交付

| 阶段 | 输出 | 检查重点 |
|---|---|---|
| 视觉方向 | 少量比例／风格候选，战斗尺寸对照 | 脸、轮廓、比例、角色辨识度 |
| 母图确认 | 确定版本与透明背景素材 | 头脚完整、朝向一致、道具与手的位置 |
| 运动规划 | 动作表、部件表、转轴与遮挡草图 | 哪些部位刚性，哪些弯曲，运动后会露出什么 |
| 部件制作 | 可见部件、遮挡补画、必要替换附件 | 接缝余量、隐藏表面、关节纹理连续性 |
| 组装 | 层级、枢轴、网格、材质和图集 | 静态轮廓与母图一致、实例状态隔离 |
| 动作 | 关键姿势、时间曲线、事件时点 | 支撑与重心、前后动作衔接、道具握持 |
| 审查与接入 | 固定版本预览、反馈记录、实际安装包 | 战斗尺寸、实际速度、游戏层级与生命周期 |

母图确认后优先局部修改。每次交付给审查者提供可点击文件或可访问预览、版本标识、修改点和需要判断的问题；在参考图尚未确认时保留备选方向。

## 生图与本地组装如何分工

生图用于视觉候选和复杂表面补画；本地工具负责尺寸、转轴、部件定位、动画轨道与资源接入。文字指令中的坐标或对齐要求仍需对输出实测。可复用提示词框架：

> 以附带的已确认母图为视觉依据。目标部件：{部件}；用途：{将暴露的表面／运动范围}。保持{脸、比例、服装、材质、光照}一致。输出{单部件／分区布局}，{朝向}，透明背景，完整边缘与{接缝余量}。与{相邻部件}衔接。参考{版本}，本次只调整{修改范围}。

每次记录输入参考、提示词、工具与日期、输出文件及哈希、审查结果。生成图像属于美术输入，按自己的授权及 `ART_SOURCE_DIR` 管理。确定性裁切、打包与重命名用本地脚本；具体工具调用按所用生图服务的能力执行。

## 为运动准备素材

先用目标动作的关键姿势检验拆件。弯曲肢体通常需要独立段、合理转轴及关节覆盖；布料和头发可用网格或附加节点。复杂动作可使用替换附件或额外手绘姿势。选型取决于轮廓、纹理、运动幅度和投入。

补画覆盖“平时被遮住、运动后露出”的表面。转轴放在解剖连接处，接缝余量由实际转角决定。材质高光、花纹和边缘厚度也会暴露不连续，审查同时看正常尺寸和放大图。

## 动作先有意图，再有曲线

为每个动作写清触发条件、循环方式、入口姿态、关键时点、退出条件，以及可否被其他动作打断。死亡、离场或受击的具体表演由角色性格与玩法选择。

涉及重力和支撑的动作，先标重心变化与接触点，再安排脚、腿、躯干、头和服装的先后关系。漂浮、飞行或消散角色则使用相应约束。角度连续只说明数学曲线连续，自然程度还要在正常速度下审查。

## 可复现的输入

部件规格记录纹理相对路径、裁切区域、枢轴、父子关系和局部绘制顺序；动作规格记录时长、轨道、循环和关键事件。工具版本与配置一起留存。生成文件先写临时位置、规范化不稳定标识，再比较内容，仅在内容变化时替换正式输出。先验证所需输入齐全，再生成整批资源。
