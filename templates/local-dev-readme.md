# 本地开发资料入口

本目录整体忽略。先维护 [工作区地图](workspace.md)，再阅读仓库的开发文档与事故防护说明。

- 设计原件与升级参考：在地图中登记自己的目录，公开摘要提取到 docs/history/design/。
- 设计待确认项、实现批次与试玩证据：在本目录按主题记录，已裁定规则同步公开设计文档。
- 游戏源码、对应版本引用、RitsuLib、SDK、Godot、美术母版：地图记录本机路径，根目录 .local-dev.env 提供脚本配置。
- 工坊脚手架：workshop/；先补配置、封面和描述，再由维护者明确授权发布。

任何流程不得依赖其他角色 Mod 的私有目录；通用原版源码和依赖包可以在本机共享。
