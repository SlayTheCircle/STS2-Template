# 工作区地图（填写自己的实际路径）

| 输入 | 本机位置 | 用途 |
|---|---|---|
| 原始设计案／卡表／升级参考 | 待填写 | 设计依据；待确认项单独记录 |
| 美术母版 | 待填写 | ART_SOURCE_DIR；保持原件 |
| 当前目标最新版原版参考源码 | 待填写 | 按目标分支最新版查原版先例；旧源码仅作历史参考 |
| 当前目标最新版编译引用 | 待填写 | GAME_REFS_DIR；过渡双目标的额外引用变量以 .local-dev.env.example 为准 |
| RitsuLib 完整包与 API 文档 | 待填写 | RITSULIB_DIR；选择与当前游戏 API 相容的 compat，不据此承诺旧版支持 |
| .NET／Godot／ImageMagick | 待填写 | 编译、导入与美术派生 |
| 游戏安装／试玩日志 | 待填写 | GAME_DIR／GAME_LOG；部署前检测游戏进程 |

所有实际路径保持私有。公开规则见 docs/dev/README.md；历史失败模式见 docs/history/incidents.md。
